# Locust brand assets

Traced from the source engraving (540x330 raster) to true Bezier outlines. Each file is a
single `fill-rule="evenodd"` path with no embedded bitmap, so it scales, recolours and prints.

| file | use |
|---|---|
| `locust-mark.svg` | the insect alone |
| `locust-wordmark.svg` | LOCUST, outlined -- needs no font |
| `locust-logo.svg` | mark + wordmark, white, transparent ground |
| `locust-logo-black.svg` | the same lockup in black, for paper |
| `locust-logo-on-dark.svg` | the lockup with its dark plate |

Identity plate, palette and type: https://claude.ai/code/artifact/98504713-41e8-4ea1-826b-8e50bf34a7e1

## Open

the engraving works as an icon -- every attempt at the head drags in wing bases and front legs.
A usable small mark has to be drawn as a simplification of this one rather than cropped from it.
Until it exists, use the wordmark alone below 48 px.

The trace is as sharp as its source allows. If a higher-resolution original of the artwork turns
up, re-tracing it would sharpen the finest venation.
